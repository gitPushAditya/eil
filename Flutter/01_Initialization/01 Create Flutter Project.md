# Create Flutter Project

## If you want same name for project and folder:

```
flutter create routineflow
```

---
## If you want different names:

```
flutter create --project-name my_project_name my_folder_name
```

---
## With Package Name(recommended)

```
flutter create --project-name project_name --org com.visionforcestudio folder_name

```

eg.
```
flutter create --project-name routine_flow --org com.visionforgestudio RoutineFlow
```
